# Voss Medical

A local, fictional doctor-clinic website inspired by the supplied screen recording, with a new identity, copy and cobalt/apricot theme.

Run `npm start` from this directory, then open http://localhost:3000. No package install or build step is needed. All assets and libraries are served locally.

Features: live particle DNA helix using Three.js, GSAP blur reveals and parallax, Lenis smooth scrolling, responsive layouts, scroll-driven horizontal care cards, service and doctor dialogs, mobile navigation, reduced-motion support, elastic pointer interaction and a validated demonstration contact form.

The consultation form is a frontend demonstration. It does not send, save or process patient details. Doctor names and biographies are fictional; photographs are stock illustrations. Connect a real scheduling backend and replace fictional clinic details before production use.

Libraries: Three.js 0.170.0 (MIT), GSAP 3.13.0 (standard license), Lenis 1.3.23 (MIT). Font: Manrope (SIL Open Font License).

Reference documentation: https://gsap.com/docs/v3/Plugins/ScrollTrigger/ and https://github.com/darkroomengineering/lenis

Stock imagery (Pexels license: https://www.pexels.com/license/):
